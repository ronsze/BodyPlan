# CLAUDE.md 작성법

목적: 프로젝트 CLAUDE.md를 공식 규격과 하네스 원칙에 맞게 작성한다.

## 파일 규격

- `./CLAUDE.md`: 팀 공유, 세션 시작 시 항상 로드. `./CLAUDE.local.md`: 개인용(.gitignore).
- 하위 디렉토리의 CLAUDE.md는 그 디렉토리의 파일을 Read할 때 지연 로드된다.
- `@경로` 임포트 가능(재귀 4단계). 백틱으로 감싸면 리터럴. HTML 주석(`<!-- -->`)은 컨텍스트에서 제외된다.

## 작성 규칙

- **200줄 미만 유지**: 초과하면 `.claude/rules/`나 스킬로 분리한다.
- **넣는 것**: 모든 세션에서 필요하고 변경 빈도가 낮은 것 — 빌드·테스트 명령, 컨벤션, 아키텍처 결정, "항상 X 한다" 규칙.
- **보내는 것**: 멀티스텝 절차 → 스킬. 특정 경로에만 적용 → rules. 강제가 필요한 규칙 → 훅 (CLAUDE.md는 권고일 뿐 강제하지 못한다).
- **검증 가능하게 구체적으로**: "깔끔하게"가 아니라 "들여쓰기 2칸"처럼 지켰는지 판정 가능한 문장으로 쓴다.
- **모순 제거**: 추가할 때 기존 규칙·다른 로드 파일(user CLAUDE.md, rules)과 충돌하는지 대조한다.

## 템플릿

```markdown
# CLAUDE.md

## <주제별 섹션>

- <항상 적용할 규칙. 판정 가능하게 구체적으로>
```

## 검증

- 분량: `wc -l CLAUDE.md`로 200줄 미만인지 확인한다.
- 준수: 새 세션에서 규칙이 적용되는 대표 요청 하나로 실제 지켜지는지 확인한다.
- 배치: 각 항목이 "모든 세션에서 필요한가"를 통과하는지 대조하고, 아니면 위 보내는 곳으로 옮긴다.
