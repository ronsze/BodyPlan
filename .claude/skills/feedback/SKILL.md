# feedback

목적: 하네스 결함 사례를 `.claude/FEEDBACK.md`에 기록해 추후 개선의 근거를 남긴다.

## 절차

1. 문제가 하네스 결함에서 온 것인지 판정한다. 판정 기준: 구성요소가 존재했거나 올발랐다면 이 문제가 예방됐는가. 아니면 기록 없이 종료한다.
2. FEEDBACK.md의 분류 중 하나를 고른다. 해당하는 것이 없으면 `미분류`.
3. FEEDBACK.md의 기록 형식대로 한 줄을 추가한다.
4. 진행 중이던 원래 작업으로 복귀한다. 하네스는 고치지 않는다.

## 경계

- 대상: 하네스 결함 여부 판정과 기록.
- 비대상: 하네스 수정·개선, 하네스와 무관한 코드 버그의 기록.

## 종료 조건

기록 한 줄이 추가되었거나, 하네스 결함이 아니라고 판정했으면 완료.

## 실패 시

결함 여부를 판정할 수 없으면 사용자에게 묻는다.

## 검증

- 호출 적절성: 절차 지적 사례에는 로드되고, 일반 코드 버그 제보에는 로드되지 않는지 확인한다.
- 목적 달성: 추가된 기록이 FEEDBACK.md의 형식·분류와 일치하는지 확인한다.
